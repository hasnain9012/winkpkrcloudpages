# WinPKR WordPress-Style Static Website

This package is a responsive static HTML site designed from the supplied reference screenshot:
- white/black only
- thin bordered WordPress-like cards
- responsive mobile navigation
- semantic HTML
- topical-cluster internal linking
- Article, FAQPage, BreadcrumbList and VideoObject JSON-LD
- Contact Us, Privacy Policy, About Us and Disclaimer pages
- external source links to Google Play policy, Pakistan Code and JazzCash terms

## Important: homepage DOCX
The DOCX mentioned in the request was not attached to this conversation. I used the existing WinPKR homepage content available in the project library as the current content source. If you want the exact DOCX wording used instead, upload that DOCX and replace the homepage copy.
